# 公开数据集（候选）

> 2026-11-12 检索所得。**只确认了条目存在和页面描述，没有下载，没有核对许可证和文件内容。**
> 任务 S2.1 负责逐个下载、核对并回填下表的"核对结果"列。

我们拿不到合作博物馆的实测数据。下面这些公开数据不能用来校准"我们的建筑"，但能做三件事：

1. **真实气候检验**：把实测的馆内温湿度序列输入文物响应和损伤模型，确认模型在真实气候下给出合理结果。
2. **参数取值范围**：有室内外成对数据的，用来辨识自由运行时的渗透和湿缓冲参数，给敏感性分析提供有实测依据的范围。
3. **能耗量级核对**：有能耗数据的，用来核对库房工况的能耗量级。

## 使用规则

- 原始数据放 `data/raw/<编号>/`，该目录已在 `.gitignore` 中，**不要提交数据文件**。提交下载脚本 `scripts/data/fetch_<编号>.py` 和校验和。
- 每个数据集在使用前记录：许可证、时间范围、采样间隔、缺测比例、传感器精度、是否有室外同步数据。许可证不允许再分发或不允许用于研究的，不用。
- 论文里按数据集各自要求的方式引用数据集本身和对应论文。
- 论文里不得把这些数据描述成"对本文建筑模型的校准"。准确的说法是"用公开实测序列检验损伤模型"和"参数范围取自公开实测数据"。
- 如果检索到更合适的公开数据集（特别是亚洲湿热气候、带能耗的），加到表里并在 `docs/PROGRESS.md` 里说明。
