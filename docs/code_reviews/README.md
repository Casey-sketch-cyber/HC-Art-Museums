# 代码与结果审查记录

审查者（Claude）对每个 PR 的审查意见都保存在这里，与 PR 评论内容一致。**有的 AI 读不到 GitHub 的 PR 评论，所以以这里的文件为准。**

- 文件名：`PR<编号>_<任务编号>.md`，同一个 PR 的多轮审查写在同一个文件里。
- 被退回的 PR：按文件里"必须改"的条目逐条修改，改完推送到同一分支，状态改回"待审查"。
- 谁都可以接手被退回的 PR，不限于原作者；接手前先在 `docs/PROGRESS.md` 的"当前分工"表里改成自己的名字。

注意：`docs/reviews/` 是留给期刊审稿意见的，不要和这里混用。
