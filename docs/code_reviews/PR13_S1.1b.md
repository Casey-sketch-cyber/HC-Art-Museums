### 留给后续任务的说明（不阻塞）

- historic 档把未涂覆云杉板的 MBV（1.16）用于全部墙面和顶棚，而石灰灰泥不在 Round Robin 材料表里。这是"强缓冲历史内饰"原型的取值，属于假设，S4.4 的湿缓冲敏感性要覆盖它，写论文时也要这样表述。
- 推导用的是"从平衡态出发的一次阶跃在 8 h 内的吸湿量"，NORDTEST 测的是 8/16 h 循环稳态，两者有差别，属于一阶模型的近似。在 `MODEL.md` 4.1 节加一句即可，可以在后续 PR 里顺带补上。
