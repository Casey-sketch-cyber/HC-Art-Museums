## 必须改

### 1. 平滑最大值严重低估峰值（`src/museum_v2/damage.py` 的 `_smooth_max`）

现在的写法是 log-mean-exp：`(logsumexp(γx) − log N) / γ`。减去 `log N / γ` 后，它不再是"最大值的近似"，而更接近一个加权平均。γ = 2500 时，N = 8760 对应的偏差是 `log(8760)/2500 ≈ 0.0036`，几乎等于屈服应变 0.004。

审查时的实测：

| 输入 | `max_strain_ratio`（平滑） | `exact_max_strain_ratio` |
|---|---|---|
| 一整年逐时波形，木板画 | 0.028 | 0.080 |
| 一整年逐时波形，木雕 | 0.170 | 0.460 |
| 一整年逐时波形，漆器家具 | 0.227 | 0.346 |
| 8760 小时里只有 1 小时 RH 跌到 30% | 0.043 | 0.844 |

后果：F4 和 F5 要把 `max_strain_ratio` 当约束或损失用，优化器会把应变推到屈服以上，平滑值却仍显示安全。现有测试只断言"平滑值 ≤ 精确值"，所以没发现。

**怎么才算改好：**
- 在无量纲的应变比（`|ε| / ε_yield`）上取平滑最大值，用不减 `log N` 的 LogSumExp，使它成为**上界**（对约束来说是保守方向）；γ 取得足够大，让 `log(N)/γ ≤ 0.01`（例如比值尺度上 γ ≥ 1000）。也可以用别的写法，但要满足下面的测试。
- 新增测试：上表的"整年波形"和"单次尖峰"两种输入，平滑值都满足 `exact ≤ smooth ≤ exact + 0.02`。
- 梯度测试（NumPy 解析 VJP 和 torch gradcheck）在新写法下继续通过。
- 检查其他地方有没有用同样的 `_smooth_max`，一并改。
