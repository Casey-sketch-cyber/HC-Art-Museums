# iScience 稿件骨架

这是按 2026-11-12 核对的作者须知留出的章节，不是 Cell Press 的官方模板。官方 Word 和 LaTeX 模板在 <https://www.cell.com/information-for-authors/article-templates>。须知里的字数、条数和费用见 `docs/ISCIENCE_REQUIREMENTS.md`。

- `main.tex`：终稿主文件的章节顺序。里面没有结果，也没有作者信息。
- `highlights.txt`：留给以后的 3–4 条 Highlights。现在是空的。
- 图形摘要还没有文件。规格是 1200×1200 像素、300 dpi 的正方形，TIFF、PDF 或 JPG。不要用通用生成式图像工具制作。

旧稿在 `paper/main.tex` 和 `paper/rineng/`，不要把那里的句子或数字抄进这个目录。
